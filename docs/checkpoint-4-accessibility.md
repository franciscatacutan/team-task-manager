## Changes and purpose

- **Contextual search:** projects say Search projects, tasks say Search tasks and members have an explicit Search members name. Shared `SearchBar`/`Toolbar` labels are now required by TypeScript, so a new caller cannot silently inherit the wrong domain. Team selection and profile team lists explicitly supply Search teams; user search retains Search users. Filtering/query behavior is unchanged.
- **Responsive lists:** the audited team, project, task, user and member lists keep normal vertical flow in their main page/workspace scroll container when width **or** height is below **48rem (768px at the default root size)**. A table then scrolls horizontally as necessary. At larger widths/heights, existing bounded flex layouts retain vertical table scrolling and sticky headers. Explicit layout markers cover list parents, tab/content chains and profile team tables; the shell, headers and business views are retained. The small member list no longer collapses beneath its header/toolbar.
- **Keyboard scrolling:** shared `Table` observes its container/table geometry and window resizing. Only actual overflow adds a named region and a tab stop; arrow keys use native scrolling. When the table fits, both the extra tab stop and region label disappear. Table semantics, caller attributes/ref, sort controls and links remain intact. Observation is cleaned up on replacement/unmount, with resize measurement when ResizeObserver is unavailable.
- **Original contrast fixes:** avatar initials/group-count defaults use existing foreground at 75% opacity; the log-avatar override matches. Neutral User/Member badges and unread notification labels/body/time use that established readable foreground treatment on their existing tinted surfaces. Primary/accent palettes and unrelated typography/layout choices were not redesigned.
